
# AI Career Assistant

Welcome to AI Career Assistant!

AI Career Assistant is a web-based platform designed to help students choose the right career according to their education, skills, and interests.

## Features

1. AI Career Recommendation
2. Chatbot with Voice Support
3. Skills Assessment
4. Career Roadmap
5. Job Search
6. CV Generator
7. Interview Preparation
8. English Learning
9. Quiz System
10. Study Planner
11. Motivation Section
12. Feedback System

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- GitHub Pages

## How to Use

1. Open the website.
2. Enter your education and skills.
3. Select your career interests.
4. Get career recommendations.
5. Explore other career tools.
